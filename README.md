# Living Balmora

Living Balmora enhances Balmora by adding subtle clutter, decorations, and small environmental details while preserving the original atmosphere and gameplay.

The goal is to make the city feel more alive without adding too much.


## Features

- Vanilla assets only
- No gameplay changes
- No quests
- No new NPCs
- Lightweight and lore-friendly
- Compatible with OpenMW and original Morrowind


## Installation

Copy `LivingBalmora.esp` into your `Data Files` directory and enable it.
